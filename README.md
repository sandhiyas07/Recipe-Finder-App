# 🍳 Recipe Finder App

A modern, responsive Recipe Finder web application built using HTML, CSS, and JavaScript. Discover delicious recipes, search by recipe name or main ingredient, explore cooking instructions, and save your favorite meals.

## ✨ Features

- 🔍 **Recipe Search** — Search recipes by name or main ingredient.
- 🥗 **Recipe Categories** — Browse recipes by category.
- 🍽️ **Recipe Cards** — View food images, recipe names, and cuisine information.
- 📖 **Recipe Details** — Explore ingredients and step-by-step cooking instructions.
- ❤️ **Favorites** — Save and remove favorite recipes.
- ☑️ **Ingredient Checklist** — Check off ingredients while preparing a dish.
- 🔤 **Sorting** — Sort recipes alphabetically from A–Z or Z–A.
- 🎬 **Cooking Videos** — Open YouTube recipe videos when available.
- 💾 **LocalStorage** — Keep favorite recipes saved in your browser.
- 📱 **Responsive Design** — Works on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/Recipe-Finder-App.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the Project

Open the downloaded `Recipe-Finder-App` folder in Visual Studio Code.

### 3. Run the Application

1. Install the **Live Server** extension in VS Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.
4. The application will open in your browser.

No build tools or API key are required for the public TheMealDB test endpoint used in this project.

## 🔎 How to Use

1. Open the Recipe Finder App.
2. Enter a recipe name, such as `Arrabiata`, or an ingredient, such as `Chicken`.
3. Select the appropriate search mode.
4. Click **Find Recipes**.
5. Browse the available recipes and select a recipe card.
6. View the ingredients and cooking instructions.
7. Use the heart icon to add recipes to your favorites.
8. Open **Favorites** to view your saved recipes.

## 🌐 API Used

**TheMealDB API**

The application uses TheMealDB to retrieve recipe information, food images, ingredient lists, and cooking instructions.

API documentation: https://www.themealdb.com/api.php

An internet connection is required to retrieve recipe data.
